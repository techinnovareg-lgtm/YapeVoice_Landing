## 🚀 Despliegue en GitHub Pages

1. Asegúrate de que el repositorio tenga GitHub Pages habilitado.
2. Ve a **Settings → Pages**.
3. En **Source**, selecciona la rama `main` y la carpeta `/landing` (o raíz si copiaste los archivos directamente).
4. Guarda y espera ~1 minuto. Tu página estará en:
   `https://<tu-usuario>.github.io/<nombre-repo>/`
